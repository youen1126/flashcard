# ✦ Flashcard Studio ✦

Dark Mode Tech Aesthetic 風格的單字卡練習工具，單一 HTML 檔案，無需安裝、無需伺服器，用瀏覽器直接開啟即可使用。

## 功能

- **多卡片組** — 建立多個獨立的卡片組（例：英文單字、歷史問答、面試題）
- **自由填寫** — 正面與背面不限格式，可填單字、論述題、任何問答內容
- **練習模式** — 點擊卡片翻面（3D 動畫）、上 / 下一張導航、亂序開關
- **自動儲存** — 資料存於瀏覽器 `localStorage`，重開瀏覽器不遺失

## 使用方式

直接下載 `flashcard.html`，用任意瀏覽器開啟即可，不需網路連線（字型除外）。

```
下載 flashcard.html → 雙擊開啟 → 開始使用
```

## 設計風格

Dark Mode Tech Aesthetic：深色背景、電網格、霓虹發光按鈕、玻璃擬態卡片、環境色光暈。

## 技術

純 HTML + CSS + Vanilla JavaScript，零依賴，零框架。
